Q6.Vads tag and execute protection are strong indicators of malicious processes; can you find which they are? (ANSWER format: Pid1;Pid2;Pid3) 
hint: There are only 3 pids meeting this criteria.
how to response: gunakan command berikut python3 vol.py -f victim.raw -r json windows.vadinfo > vad.json windows.vadinfo adalah plugin Volatility 3 yang membaca dan menampilkan VAD (Virtual Address Descriptor) dari proses di memory dump.
setelah itu kita harus memphrase hasil file json dengan kode pyton berikut untuk temukan PID yang menggunakan "PAGE_EXECUTE_READWRITE"
source code py:
import json

# Load VAD json
with open("vad.json", "r") as f:
    vad_data = json.load(f)

# Filter untuk Protection == PAGE_EXECUTE_READWRITE
pids = set()
for entry in vad_data:
    prot = entry.get("Protection", "")
    if prot.upper() == "PAGE_EXECUTE_READWRITE":
        pid = entry.get("PID") or entry.get("pid")
        if pid:
            pids.add(pid)

# Ambil 3 PIDs pertama (sorted)
top3 = sorted(pids)[:3]

# Output sesuai format
print(";".join(str(pid) for pid in top3))
