Your task: inspect the provided pcap and produce artifacts for detection tooling (domains, IPs, submission dates, related email, etc.). Tools used here: TShark and VirusTotal.

How we search HTTP requests with TShark

Run this TShark command to list hosts and request URIs from the pcap:
tshark -r ~/Desktop/exercise-files/teamwork.pcap -Y "http.request" -T fields -e http.host -e http.request.uri

Why this works (short & simple):

tshark — CLI version of Wireshark.

-r <file> — read capture file (not live).

-Y "http.request" — show only HTTP request packets (GET/POST).

-T fields — output specific fields in columns.

-e http.host and -e http.request.uri — show destination host and requested path.
Result = two columns (host | path). Combine them to get the full URL for each HTTP request.

To defang a URL (safe for sharing), use CyberChef or manual replacement (e.g., http → hxxp, . → [.]).

Q5 — What is the email address that was used? (defanged format: aaa[at]bbb[.]ccc)

How we found it: Search for HTTP POST packets that contain @ (likely user/email data):

We found frames containing @ at frames 202 and 122. Show the full verbose frame for the frame with the email:

Inspect the HTTP body in that verbose output — the email appears there. Defang it.

The pcap contains HTTP traffic to a domain clearly crafted to impersonate PayPal. The domain was first submitted to VirusTotal on 2017-04-17 and resolves to 184[.]154[.]127[.]226.
The attacker exfiltrated or posted an email (johnny5alive[at]gmail[.]com) via an HTTP POST, suggesting credential or form-data capture.
